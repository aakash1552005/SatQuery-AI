## Quick Start: How to Present

### Option A: Microsoft PowerPoint / Google Slides
1. Open [`SatQuery_AI_SIH2026_SatSense_V2.pptx`](file:///c:/Users/AAKASH.S.S/OneDrive/Desktop/SatQuery%20AI/sih_presentation/SatQuery_AI_SIH2026_SatSense_V2.pptx).
2. Press **`F5`** to start the slideshow.
3. Use the script in [`SPEAKER_NOTES_AND_DEFENSE_GUIDE.md`](file:///c:/Users/AAKASH.S.S/OneDrive/Desktop/SatQuery%20AI/sih_presentation/SPEAKER_NOTES_AND_DEFENSE_GUIDE.md) for slide-by-slide narration.

### Option B: Interactive Web Presentation
1. Double-click or open [`index.html`](file:///c:/Users/AAKASH.S.S/OneDrive/Desktop/SatQuery%20AI/sih_presentation/index.html) in your web browser.
2. Keyboard Shortcuts:
   - **`Right Arrow`** / **`Spacebar`**: Next Slide
   - **`Left Arrow`**: Previous Slide
   - **`F`**: Toggle Fullscreen Mode
   - **`N`**: Toggle On-Screen Speaker Notes Drawer
3. To export as a PDF: Press **`Ctrl + P`** in Chrome/Edge, select **"Save as PDF"**, set Orientation to **Landscape**, and check **"Background graphics"**.
