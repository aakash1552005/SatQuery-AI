## 2. Identified Contradictions in Existing Reports

1. **Synthetic Sample Misconception**: `scripts/generate_bigearthnet_samples.py` generated 4 synthetic dev pairs (`BEN_S1_S2_patch_001` through `004`) with uniform gradient pixels. Earlier comments called these "downloaded samples". **Correction**: Explicitly tag them as `DEVELOPMENT_SYNTHETIC_FIXTURE` in manifests and never claim they represent real benchmark imagery.
2. **Dataset Acquisition Status**: Previous summaries occasionally stated "All required real datasets are acquired". **Correction**: Distinguish `METADATA_READY` (Parquet and JSON annotations acquired) from `IMAGE_DATA_READY` (raw full-resolution S1/S2 and aerial imagery pending or storage-constrained).
3. **Storage Strategy**: Local drive `C:\` has ~106 GB free. The project lacked an explicit environment variable override for external storage mounts. **Correction**: Fully implement `SATQUERY_DATA_ROOT` support across gateway, data loaders, and manifests.
